ABOUT THIS SITE

Every verdict on this page is produced by a single versioned prompt sent to the Claude API, which returns a schema-validated JSON report. That prompt is not trusted on vibes: it is scored by an offline eval suite of graded test cases — code graders plus an LLM-as-judge — that runs in CI on every commit and publishes a scoreboard.

Run bie evals run locally to reproduce the scoreboard.
